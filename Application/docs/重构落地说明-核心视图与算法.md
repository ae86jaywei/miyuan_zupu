## 二、数据结构变化

### 2.1 `PersonNode`

```ts
branchId: string          // 所属房支标识（顶级房根 uid）
branchName: string        // 长房 / 二房 / 三房 …
branchRootUid: string     // 房支始祖 uid（气泡锚点、分页跳转目标）
branchParentUid: string   // 上一级分支根
branchLevel: number       // 0 本支、1 房、2+ 深层
isBranchPoint: boolean    // 多子或后代 > 45
```

标记规则：

1. 宗支根为「本支」，层级 0；
2. 根的直接子女按长幼成为房支：`长房/二房/三房…`，层级 1；
3. 更深节点继承所属房，只更新 `isBranchPoint`；
4. 配偶卡跟随主卡房支（`inheritBranchToSpouses`），避免全览气泡把配偶误计入「本支」；
5. 使用显式栈 + `seen` 集合，避免深链递归爆栈与环数据死循环。

### 2.2 `PagePlan`

```ts
contextAncestors: string[]        // 页根上溯两代 uid
contextAncestorNames: string[]    // 与 uid 对应的姓名
branchName: string                // 本页所属房支
siblingLinks: PageJump[]          // 旁支 → 起页
```

`PageJump`：`{ uid, name, page, relation }`，`relation` 形如 `二房·韦承恩`。

## 三、算法细节

### 3.1 分支点优先切页

在原有「容量装箱 + 承接父卡」之间增加一次前置判定（`PaginationService.shouldCutBeforeBranchPoint`）：

- 当前页已排 ≥ 20 人；
- 下一个待排节点是房支起点（`branchRootUid === uid`）且 `isBranchPoint`；
- 当前页已混入其他房支。

同时满足时先落页，再从新房起点开页。这样同一房支的树冠不会被拆到多页反复绘制，同时保留原有整房装箱、指数回退试探与跨页承接卡机制。

### 3.2 页首/页脚信息（`decoratePages`）

`buildIndex` 完成「人物 → 首次出现页」后执行：

1. `branchName`：取页内首个节点的房名；
2. `contextAncestors`：从页根沿 `father ?? mother` 上溯 2 代；
3. `siblingLinks`：页根为房根时，取父节点下其他房根，按 `book.pageOf()` 解析起页，最多 4 条。

### 3.3 房支聚簇与防重叠

`TreeCanvasShared.aggregateByBranch`：

- 只统计 `branchLevel ≥ 1` 的可见盒子，根节点单独兜底；
- 按 `branchId` 分组，一房一个气泡；
- 锚点优先取「房根卡」中心，房根不在视口内时取组内平均位置；
- 气泡标题 `房支·代表名`，副标题 `总人数`（房根 `descendants`）；
- `avoidOverlap()`：同世代 Y 轴对齐，按 `bx` 排序后依次右推，最小间距 6vp，保证 5% 全览互不遮挡。

LOD 阈值同步调整为：`< 22%` 房支聚簇、`22%~55%` 姓名骨架、`≥ 55%` 完整卡片；手势中仍主动降一级。

### 3.4 按房支分卷

`PdfExportService.planVolumes` 优先走房支分卷：

1. `branchIndex()` 从当前宗支树构建 `uid → { branchName, rootUid, rootName }`，配偶同步映射；
2. `planBranchVolumes()` 按 `rootUid` 分组，保持人物原顺序；
3. 单房 ≤ 上限直接成卷，卷名为 `第N卷（长房·韦XX）`；
4. 单房超限时复用 `slicePeopleByGeneration()`（世代 + 家庭单元，夫妻不拆卷），续卷标「·续」；
5. 房支信息覆盖不足 80%（导出子集不属于当前树）时，自动回退旧世代分卷。

## 四、交互闭环

1. **全览**：低缩放下每房显示「三房·韦耀定 25人」卡片；点击 → `openBranchPage()`：
   - 上溯目标 `rootUid`，切换宗支；
   - `PaginationService.book()` 计算页码；
   - 写入 `pagedMode`，`viewState = 'PAGED'`，定位到该房起页。
2. **面包屑**：顶部显示「根 › 房 › 支 › 当前」，点击任一级 → `centerOnUid()` 居中并高亮。
3. **小地图**：仅在 SM 及以上断点显示（手机窄屏自动隐藏，不影响既有布局）；显示宗支缩略条与当前视口框，点击任意位置快速跳转。
4. **分页阅读**：
   - 页首浅灰虚线卡显示上溯两代祖先，点击跳回祖先页；
   - 页脚「旁支 二房·韦XX → 第N页」直达兄弟房；
   - 页面横向滑动 60vp 翻页（左滑下一页、右滑上一页）。

## 六、与全案的有意差异

| 全案要求 | 实际实现 | 原因 |
|---|---|---|
| `@State viewState: 'MAP' \| 'PAGED' \| 'FOCUS'` | 新增 `viewState` 字符串状态，以 `pagedMode` 为渲染真相源 | 避免两套状态不同步；页面导航栏仍只依赖 `pagedMode` |
| Swiper 包裹 PageSheet | 页面级水平 `PanGesture` 翻页 | 避免 Swiper 与页内 Scroll 嵌套导致多设备布局抖动，符合「不改一多适配」约束 |
| TaskPool 执行 `generatePagePlan` | 保留主线程协作式 `yieldToEventLoop` | 分页结果含 `PersonNode` 引用与 `Set`，无法直接跨线程序列化；现有 TaskPool 空任务 yield 已解决 THREAD_BLOCK_6S |
| 气泡文字作为 PDF 文本层 | 页首/页脚文本层已落地，气泡房支名未单独叠加 | PDF 分页版不渲染全览气泡；房支信息已通过页眉、页首承接与页脚软链接进入文本层 |
| 每页 30~50 人固定切片 | 保留容量装箱 + 分支点优先换页 | 避免固定人数导致大卡/长名溢出，保持既有纸张适配能力 |
