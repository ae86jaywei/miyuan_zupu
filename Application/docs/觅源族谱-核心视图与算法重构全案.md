# 觅源族谱-核心视图与算法重构全案

**文档版本**：V3.0（基于基线 c1aa131 深度定制）
**适用模块**：端侧 ArkUI 渲染引擎、分页排版引擎
**核心目标**：解决大族谱“全览重叠看不清”、“自动分页生硬断裂”、“地图与分页割裂”三大痛点。打造“数据一棵树，视图两模式，导航全闭环”的丝滑体验。

---

## 一、 现有架构痛点与重构目标

结合当前代码现状，我们不需要推翻底层（RDB + Outbox + LRU缓存依然完美），重点需要重构上层视图与排版层：

1.  **全览视图（LOD 降级不够智能）**：现有的 `TreeCanvasShared.aggregateEu()` 生成的气泡仅显示数字（如 `13`），用户不知道是谁。需改为**“房支聚簇”**（如“三房·韦小宝 13人”）。
2.  **分页视图（PaginationService 切分生硬）**：当前的固定容量切分，导致同一祖先的树冠在多个页面重复渲染。需改为**“分支点 DFS 智能切片”**。
3.  **状态割裂**：`EuTree` 的平移缩放与 `PagedTree` 的翻页是割裂的，需实现**“气泡即目录，点击即跳转”**。

---

## 二、 核心架构设计：三位一体渲染流
[族谱数据] (扁平 People 列表)
│
▼ (TreeBuilder 建树 + 标记分支点)
[单棵大树结构] ──┬─> [宏观地图模式] 视口剔除 + LOD分级 (EuTree/TreeCuller)
│ ├─ 缩放 <15%: 显示房支聚簇卡片 (点击 -> 跳转分支)
│ └─ 缩放 >50%: 显示具体人物 (点击 -> 查看详情)
│
└─> [中观阅读模式] 按分支点 DFS 切片 (PaginationService)
├─ 页首: 祖先上下文链
├─ 主体: 30~50 人 (完整脉络)
└─ 页脚: 兄弟分支软链接

## 三、 核心算法与数据结构重构（重点）

### 3.1 算法一：基于“分支点”的智能切页算法（重构 `PaginationService`）

**目标**：替代现有的 `static async book()` 内部逻辑。
**前置条件**：在 `TreeBuilder.computeMetrics()` 中预计算每个节点的 `descendantCount` (后代总数) 和 `branchId` (所属房支)。

**伪代码逻辑**：
```typescript
// 核心切入点：DFS 遍历寻找切页锚点
function generatePagePlan(rootUid: string): PagePlan {
    let pages: PageContent[] = [];
        let currentPageNodes: PersonNode[] = [];
            
                // 阈值常量
                    const MAX_PEOPLE_PER_PAGE = 45;
                        const MIN_PEOPLE_PER_PAGE = 20;
                        
                            function dfs(node: PersonNode, ancestorContext: PersonNode[]) {
                                    currentPageNodes.push(node);
                                            
                                                    // 判断是否是一个分支点 (儿子数 >= 2 或 后代数 > 阈值)
                                                            const isBranchPoint = node.children.length > 1 || node.descendantCount > MAX_PEOPLE_PER_PAGE;
                                                                    
                                                                            if (isBranchPoint && currentPageNodes.length >= MIN_PEOPLE_PER_PAGE) {
                                                                                        // 触发切页
                                                                                                    pages.push({
                                                                                                                    pageRootUid: node.uid,
                                                                                                                                    contextAncestors: ancestorContext.slice(-2), // 强制保留 2 代父辈
                                                                                                                                                    nodes: currentPageNodes
                                                                                                                                                                });
                                                                                                                                                                            currentPageNodes = []; // 清空，以当前分支节点为起点开启新页
                                                                                                                                                                                        ancestorContext.push(node);
                                                                                                                                                                                                }
                                                                                                                                                                                                
                                                                                                                                                                                                        for (const child of node.children) {
                                                                                                                                                                                                                    dfs(child, ancestorContext);
                                                                                                                                                                                                                            }
                                                                                                                                                                                                                                }
                                                                                                                                                                                                                                
                                                                                                                                                                                                                                    dfs(findNodeByUid(rootUid), []);
                                                                                                                                                                                                                                        return finalizePages(pages); // 处理最后不满一页的数据，合并或单独成页
                                                                                                                                                                                                                                        }
                                                                                                                                                                                                                                        改造点：
                                                                                                                                                                                                                                        
                                                                                                                                                                                                                                        在 PageContent 数据结构中，新增 contextAncestors: string[]，记录上溯两代的 uid。
                                                                                                                                                                                                                                        
                                                                                                                                                                                                                                        删除现有的硬编码强行分页逻辑，改用上述递归切片。
                                                                                                                                                                                                                                        
                                                                                                                                                                                                                                        3.2 算法二：LOD 语义聚簇与防碰撞（重构 TreeCanvasShared.ets）
                                                                                                                                                                                                                                        目标：解决截图 1（5% 缩放）气泡乱飞、重叠的问题。
                                                                                                                                                                                                                                        切入点：class Bubble, aggregateEu(), detailLevelOf()。
                                                                                                                                                                                                                                        
                                                                                                                                                                                                                                        重写 Bubble 数据结构：
                                                                                                                                                                                                                                        
                                                                                                                                                                                                                                        移除 count: number 的单纯数字展示。
                                                                                                                                                                                                                                        
                                                                                                                                                                                                                                        增加 branchName: string（如“长房”、“二房”）。
                                                                                                                                                                                                                                        
                                                                                                                                                                                                                                        增加 anchorUid: string（该分支的始祖 uid）。
                                                                                                                                                                                                                                        
                                                                                                                                                                                                                                        增加 bbox: Rect（计算该气泡在画布上的包围盒，用于防碰撞）。
                                                                                                                                                                                                                                        
                                                                                                                                                                                                                                        重写聚合逻辑 aggregateEu()：
                                                                                                                                                                                                                                        
                                                                                                                                                                                                                                        不要贪心算法全局聚合。基于树的结构，在 generation = 3 或 generation = 4 的节点处进行子树折叠。
                                                                                                                                                                                                                                        
                                                                                                                                                                                                                                        将多个子嗣节点汇聚成一个代表节点：[ 三房·韦耀定 (25人) ]。
                                                                                                                                                                                                                                        
                                                                                                                                                                                                                                        增加防重叠逻辑（力导向/网格对齐）：
                                                                                                                                                                                                                                        
                                                                                                                                                                                                                                        如果是同一世代的分支气泡，将其 Y 轴坐标强制对齐。
                                                                                                                                                                                                                                        
                                                                                                                                                                                                                                        如果 X 轴重叠，按照 bbox 宽度进行左右平移推开，确保 5% 缩放下所有气泡均可见。
                                                                                                                                                                                                                                        
                                                                                                                                                                                                                                        3.3 数据结构扩展（TreeViewport.ets 与状态管理）
                                                                                                                                                                                                                                        将画布状态独立存储，不再依赖全局 AppStorage。
                                                                                                                                                                                                                                        
                                                                                                                                                                                                                                        新增 @State viewState: 'MAP' | 'PAGED' | 'FOCUS'，用于控制渲染引擎切换。
                                                                                                                                                                                                                                        
                                                                                                                                                                                                                                        四、 UI/UX 交互与组件级重构清单
                                                                                                                                                                                                                                        任务 P0：地图模式（EuTree.ets / SuTree.ets）
                                                                                                                                                                                                                                        □ 移除无意义的全屏游荡：引入 Mini-map（小地图），放在画布左下角。利用 TreeCuller 的视口数据，实时绘制缩略图，用户可拖拽框选区域快速导航。
                                                                                                                                                                                                                                        □ 导航横幅（面包屑）：在画布顶部增加 小宝 > 三房 > 韦承松，点击可瞬间返回祖先节点。
                                                                                                                                                                                                                                        □ 气泡交互：点击“三房·韦耀定”的气泡，触发 onTapPerson(uid)。路由拦截，将 uid 传入 PagedTree 组件，切换至分页视图。
                                                                                                                                                                                                                                        □ 性能优化：在 PanGesture 的 onActionUpdate 中，仅执行 matrix.translate，不触发重新计算；在 onActionEnd 中利用 TreeCuller.warmupEu() 重新计算可见区域并渲染。
                                                                                                                                                                                                                                        任务 P1：阅读模式（PagedTree.ets）
                                                                                                                                                                                                                                        □ 页首设计（防断裂）：利用 PaginationService 传入的 contextAncestors，在页面顶部绘制浅灰色的祖先卡片（带有虚线连接到本页页首），并提供 [返回祖先页] 按钮。
                                                                                                                                                                                                                                        □ 页脚设计（软链接）：在页面底部，如果该分支有未在本页展示的兄弟分支，渲染如 [继续查看：韦承恩以下分支 (点击跳转)] 的交互按钮，通过路由跳转到对应的 pageIndex。
                                                                                                                                                                                                                                        □ 横滑翻页：利用 Swiper 组件包裹 PageSheet，支持左右滑动翻页，提供像翻纸质族谱一样的物理反馈。
                                                                                                                                                                                                                                        任务 P2：导出端重构（PagedPdfExportService.ets / PdfExportService.ets）
                                                                                                                                                                                                                                        □ 导出的 PDF 必须完美复刻屏幕端的“页首上下文”和“页脚软链接”。
                                                                                                                                                                                                                                        □ 分卷逻辑重写：按“房支（Branch）”进行自然分卷（如 卷一：长房世系，卷二：二房世系），不要按 maxPerVolume 人数强行切。
                                                                                                                                                                                                                                        □ addTextObjects 阶段，将气泡聚簇的房支名称作为可检索的文本层叠加。
                                                                                                                                                                                                                                        五、 鸿蒙原生性能与体验规范（必做项）
                                                                                                                                                                                                                                        渲染隔离：Canvas 绘制必须在独立层，避免与 UI 控件（如悬浮按钮、导航栏）混排导致重绘。
