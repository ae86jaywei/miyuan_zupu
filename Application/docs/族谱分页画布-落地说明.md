# 族谱分页画布 · 落地说明（分支 1.0.1_FY）

本文记录 `1.0.1_FY` 上实际落地的分页方案，覆盖并修正 `族谱分页画布方案-1.0.1.md` 里的竖版尺寸与早期装箱规则。旧文档中的 220×320mm、25mm 天头地脚按本文为准替换。

## 1. 页面规格（横版）

| 项目 | 数值 |
| --- | --- |
| 成品尺寸 | 320mm × 220mm（横放，与 220×320 同纸） |
| 装订口 gutter | 20mm（默认左侧装订） |
| 翻口 fold | 15mm |
| 天头 head | 20mm |
| 地脚 foot | 20mm |
| 出血 bleed | 3mm（成品外，不占版心） |
| 版心 | **285mm × 180mm** |

- 单位换算：1mm = 3.7795vp = 2.8346pt = 11.811px(300dpi)。
- 奇偶页镜像：单页版心左边界 = 20mm，双页 = 15mm；`binding='right'` 时互换。
- 屏幕按「整页可见」缩放：`k = min(视图宽/320, 可用高/220) * 0.96 * 用户缩放`，页面按真实比例显示，滚轮/双指缩放只改显示倍率，不改版心。

## 2. 卡片与字号（标准档）

- 主卡 22mm × 10mm；世代列距 3mm；兄弟行距 2mm；苏式行距 4mm。
- 姓名 7pt、次要信息 5.5pt、线宽 0.25mm。
- 印刷版**配偶并入主卡文字**（`showSpouse=false`），既省地方，也从结构上消除夫妻卡跨页。
- 预留档位：紧凑 16×8mm、大字 28×12mm，改 `LayoutProfile` 即可，不动分页逻辑。

## 3. 分页原则：每页自成一个闭合片段

不做「大画布切片 + 边界端口标记」。每页只排本页允许出现的人（`PagePlan.uids`），布局递归遇到集合外的子女就停，因此：

> 页内每条线的两个端点都在本页，**结构上不可能出现跨页悬空线**。

跨页靠两种文字承接：

1. 页顶承接父卡：上一页被切开的父辈，在下一页顶部**重复画一张卡**，角标「承P{n}」指回首次出现页；
2. 页脚续见：父卡留在本页、子女去后页时，页脚写「续见第 a—b 页（某某以下 N 支）」。

这样下一页从承接父卡重新起线，读者看到的是完整的一小段世系，而不是一根不知连到谁的线。

## 4. 装箱算法（PaginationService.planBook）

1. **人数快速否定**：先做后序子树人数表（`buildSizeMap`），子树人数超过本页剩余槽位就不试排，避免对 1 万人大树反复跑布局。
2. **整支优先**：整棵子树能装进版心就整支放进本页，继续装下一支。
3. **满页深挖**：整支放不下时，先把这一支的根卡放进本页，然后**逐层（BFS）**把子女加进来——同一代先铺开，避免顺着单支一路钻到页宽尽头；每到一层都用真实布局试排，装不下就在该父卡处切开。
4. **续页队列**：被切下的子女带「承接父卡 = 被切开的父辈」进入下一页队列；页面落页时插回队首，保持房支、长幼顺序。
5. **页容量**：`槽位 = floor(285/(卡宽+列距)) × floor(180/(卡高+行距))`，标准档约 11×12=132；真实排版因树形留白会更少，槽位只用于快速否定。

实测（真机「韦氏宗谱」宗支1，**后代 10041 人**）：

| 版本 | 页数 | 平均人数/页 |
| --- | --- | --- |
| 整房装箱（早期） | 1295 | 7.8 |
| 拆分后仍整房装箱 | 1540 | 6.5 |
| **逐层满页填充（当前）** | **120** | **约 84** |

| 文件 | 作用 |

| `service/PrintLayout.ets` | `PageSpec`（320×220 横版、装订/翻口/天头地脚/镜像）、`LayoutProfile`（三档卡片）、mm→vp/pt/px |
| `service/PaginationService.ets` | 装页规划、承接父卡、页脚续见、按页布局缓存、人物→页码索引、`pageGenText` |

## 6. 验收不变量

1. 任一页内，所有连线两端的人物都在 `PagePlan.uids` 内；
2. 允许集合外的子女不产生卡片，也不产生任何线；
3. 每页页根只有一张卡：宗支根，或上一页切下来的承接父卡；
4. 被切子女的数量 = 下一页及后续承接页的入口数量，页脚范围可回溯；
5. 版心 285×180mm 内排版，卡片不越过装订口/翻口/天头地脚；
6. 偶数页版心镜像，装订后两页到装订线距离一致。

## 7. PDF 导出接口（本次不修）

- `PageSpec.mmToPt()`：页面尺寸直接转 PDF pt；
- `PagePlan`：页码、世代范围、允许集合、页根、页脚、奇偶页，可直接作为 PDF 每页的绘制指令；
- `PaginationService.euPage/suPage` 与屏幕共用同一份布局结果，PDF 只需把 vp 换成 pt 绘制；
- 现有 `PdfExportService` 仍是 A4 文字流式分页，未接入，留待后续替换。

## 8. 已知边界

- 默认左侧装订、标准档、房支页序；切换参数只改 `PageSpec.binding` / `LayoutProfile`。
- 苏式谱分页已接线，但真机只验证了欧式谱；苏式建议再抽一支持有数据的宗支核对页数与页脚。
- 1 万人级规划在主线程同步完成，真机首次进入分页有可感知等待；后续若要更快，可先出第 1 页、后台继续规划。
- 页脚多条续见时只显示一行，长谱可能被截断；需要时可改成两行或「详见下页」。
