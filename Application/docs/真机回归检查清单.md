## 五、回归流程

### 5.1 回归前准备

1. 确认当前分支：`DieJiFangGu`

4. 备份测试数据

### 5.2 回归执行顺序

```
1. 构建验证 → 2. 首页/登录 → 3. 编辑页 → 4. 名录/树 → 5. 云同步 → 6. 墓葬/分享 → 7. 其他页面
```

1. 记录回归结果（通过/失败/阻塞）
2. 失败项记录 bug 并修复
3. 修复后重新验证
4. 全部通过后标记回归完成
