## 一、应用介绍（可直接转发）

**觅源** 是一款面向家族修谱、续谱的 HarmonyOS 应用：把纸质族谱搬进手机，录一次、全家用、随时可查。

**核心功能**

1. **族人信息录入**
   覆盖谱名、字号、生卒（公历/农历/年号）、世代字派、父母配偶、子女出身、过继兼祧、学历职业、生平、墓葬等字段；支持照片、视频、头像。

2. **五种谱式查看**
   欧式谱、苏式谱、宝塔式、牒记式、现代创新式一键切换；支持双指缩放、拖动平移、点选人物查看详情。

3. **世系名录与统计**
   按世代分级浏览，支持搜索姓名/曾用名/编号并瞬时定位；自动统计世代、男女、生卒、字派分布等。

4. **牒记体例 PDF 导出**
   端侧原生排版，文字可选中、可搜索、可打印；支持 A4 竖版、装订方向、分卷导出与亲属页码互引。

5. **家族协作（云家族）**
   华为账号登录后可邀请族人加入同一部族谱，按谱主 / 编辑者 / 只读成员分级授权；改动可走变更审核，敏感字段仅谱主可读。

6. **祭祖寻墓与族谱黄页**
   为祖墓标注经纬度与海拔，一键调起地图导航；族谱可上架黄页，按谱名、姓氏、地域被同宗找到。

7. **数据安全与迁移**
   支持 JSON / CSV / Markdown / PDF 导入导出，本地备份与云端多谱恢复；简繁切换、深色模式、手机/平板/PC 自适应。

**我们不做的事**：不采集通讯录与短信，不做广告推送，不出售任何个人信息。
