# 韦氏宗谱排版分页方案

> **适用场景**：60000 人级族谱，纸质版尺寸 320×220mm（横版）
> **谱式**：苏式（吊线图）、欧式（竖排表）
> **核心目标**：分页合理、世系清晰、便于翻阅

---

## 一、总体原则

| 原则 | 说明 |
|------|------|
| **以父为纲** | 同一父亲的所有子女必须连续出现在相邻页 |
| **兄弟同页** | 同一父亲的子女，其分页位置必须相邻，禁止深支插队 |
| **单一世系** | 页标题禁止跨世（如"第X—Y世"），必须标明具体房支 |
| **连线闭合** | 苏式连线必须本页闭合；欧式允许竖向跨页，但需"承上/续下"标记 |
| **先分卷后分页** | 先按"房"分卷，卷内再按兄弟长幼顺序逐页展开 |

---

## 二、苏式谱（吊线图/宝塔式）

### 2.1 页面容量（320×220mm）

| 项目 | 参数 |
|------|------|
| 盒子尺寸 | 28×20mm |
| 横向间距 | 2mm |
| 每行容量 | **10 格** |
| 每页行数 | **2 行** |
| 每页总容量 | **20 格**（含父母） |
| 行间距 | 40mm（用于画连线） |
| 页边距 | 上下左右各 15mm |

### 2.2 分页单元

| 单元类型 | 内容 | 容量 |
|----------|------|------|
| **总览页** | 始祖夫妇 + 第2世全部子女 | 2 + 10×n 格 |
| **分支页** | 某世某父夫妇 + 其所有子女 | 2 + 18 格 |
| **续页** | 承接上页未排完的子女 | 同上，页眉标"续" |

### 2.3 60000 人分页流程

```
第1册：总览（1-2页）
  └─ 第1页：始祖夫妇 + 第2世前10子女
  └─ 第2页：第2世剩余子女（标"第2世之二"）

第2册起：按"房"分卷
  例：第2世有5子 → 分5卷，每卷以该子为"房祖"

  卷内分页规则：
    1. 房祖页：房祖夫妇 + 其子女全部列出
       （子女超18人时，按9人/页拆分，标"之一/之二"）

    2. 逐页展开：每个子女的子树按"先序遍历"逐页排列

    3. 兄弟约束：同一父亲的子女，其分页位置必须相邻
       顺序：长子subtree所有页 → 次子subtree所有页 → 三子...
```

### 2.4 关键规则

| 规则 | 说明 |
|------|------|
| **兄弟同页优先** | 同一父亲的子女，尽量排在同一页或相邻页 |
| **跨页断线标记** | 子女排不下时，该子女框右下角标"▼下页"，下页对应位置标"▲承上" |
| **世系标签** | 每页页眉标"第X世 ×××房"，禁止"第X—Y世" |
| **行容量** | 每行最多10格，每页最多2行（20格），留40mm连线空间 |

### 2.5 60000 人估算

| 项目 | 数值 |
|------|------|
| 平均每人生育 | 2.5 人 |
| 第2世人数 | 约 10 人 |
| 分卷数 | **10 卷** |
| 每卷人数 | 约 6000 人 |
| 每页容量 | 20 格 |
| 每卷页数 | 约 300 页 |
| **总页数** | **约 3000 页** |

## 三、欧式谱（竖排表/一代一表）

### 3.1 核心原则

**"五世一表，小宗独立"** —— 欧式经典规则，每页只画5世，超过5世另起新表。

### 3.2 页面容量（320×220mm）

| 项目 | 参数 |
|------|------|
| 家庭单元宽度 | 75mm |
| 列间距 | 5mm |
| 每行家庭数 | **4 个** |
| 父母框高度 | 25mm |
| 连线高度 | 40mm |
| 子女框高度 | 20mm/个 |
| 每页总容量 | **4个家庭 × 5人 = 20人** |

### 3.3 分页单元

| 单元类型 | 内容 | 容量 |
|----------|------|------|
| **世表页** | 某世某人夫妇 + 子女竖排 | 2 + 8 = 10 格 |
| **合表页** | 兄弟多人并列，各带小家庭 | 4 列 × 1 家庭 |

### 3.4 60000 人分页流程

```
第1册：始祖世表（1-5世）
  页1：第1世 始祖夫妇 → 第2世子女列表（简表，不展开）
  页2-10：第2世各子 逐一展开（每人1页，含其子女）

第2册起：按"房"分卷，每卷内：
  1. 卷首：该房房祖世表（1页）
  2. 逐代展开：房祖的每个儿子各占1页（含孙子简表）
  3. 五世封顶：排到第5世时，第5世每人另起新表（新页）
```

### 3.5 关键规则

| 规则 | 说明 |
|------|------|
| **五世一表** | 每页最多画5世竖向连线，第6世必须另起新页 |
| **家庭独立** | 每个"父+子女"单元独占一列，兄弟单元之间留10mm空隙 |
| **无子女者** | 集中到卷尾"附记"页，不占家庭单元 |
| **女儿处理** | 女儿若出嫁，其子女不入本谱，女儿格标"适某氏" |

### 3.6 60000 人估算

| 项目 | 数值 |
|------|------|
| 每页家庭数 | 4 个 |
| 每家庭平均人数 | 5 人 |
| 每页容量 | **20 人** |
| 总页数 | **约 3000 页** |
| 分卷 | 按第2世房数分卷，每卷300-500页 |

## 四、两种谱式对比

| 对比项 | 苏式 | 欧式 |
|--------|------|------|
| **适合场景** | 世系清晰、分支明确、便于查找 | 世代分明、每代人数少、便于阅读 |
| **60000人优势** | 兄弟同页，便于看"这一房人丁" | 五世一表，便于看"这一支传承" |
| **缺点** | 深支展开后页数爆炸 | 兄弟多时横向拥挤 |
| **推荐** | **60000人推荐苏式** | 适合5000人以下分支 |

## 五、完美分页检查清单

| 检查项 | 苏式 | 欧式 |
|--------|------|------|
| 同一父亲子女是否相邻？ | ✓ 必须 | ✓ 必须 |
| 页标题是否单一世系？ | ✓ 禁止跨世 | ✓ 禁止跨世 |
| 连线是否本页闭合？ | ✓ 禁止跨页断线 | ✓ 允许竖向跨页，但需"承上"标记 |
| 页码是否连续？ | ✓ 卷内连续 | ✓ 卷内连续 |
| 空白页是否避免？ | ✓ 每页至少排满1行 | ✓ 每页至少排满2列 |

---

## 六、最终建议

**60000人族谱，320×220mm，推荐苏式，分10卷，每卷约300页，总计约3000页。**

核心算法一句话：**"先按房分卷，卷内按兄弟排序，兄弟子树连续排，排不下标续页"**。

## 七、附录：常见错误对照

| 错误现象 | 原因 | 修复方法 |
|----------|------|----------|
| 苏式 P3 标题"第二世—第五世" | 按 Y 坐标切，不同深度节点混排 | 改为按"父辈节点"切分，禁止跨世 |
| 欧式 P2 把"明业、明朗"和"家文、淑斌"混排 | 按行填充，没按父亲分组 | 每个父亲的家庭单元之间画分隔线或分页 |
| 苏式 P2-P7 每页固定 8 个盒子 | 固定网格切分 | 改为"一组人"为单位，组内不拆 |
| 页脚页码被截断（只显示"第"） | 页脚文本框宽度不足 | 320mm 页宽，页脚框至少 60mm 宽，居中 |
| 兄弟姐妹被推送到几百页后 | 续页队列后进先出（深度优先） | 改为：父卡续页单元插到队首，子女分支单元追加到队尾 |
