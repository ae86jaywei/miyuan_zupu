# 觅源族谱 功能实现方法分析报告（详细版）

- 仓库：https://atomgit.com/ae86jay/miyuan_zupu
- 分支：`1.0.1_FY`（分析基线 c1aa131）
- 范围：端侧 `Application/entry/src/main/ets`（ArkTS/鸿蒙）+ 云侧 `CloudProgram`（AGC 云函数/云数据库）
- 说明：列出关键类名、函数名、API、接口、字段与常量，不含代码片段。

## 一、总体架构

- **端侧 RDB 为唯一真相源** + **Outbox 离线队列** + **基于 revision 的增量同步**
- 大树渲染 = 布局 LRU 缓存（`TreeLayoutCache`）+ 二分索引视口裁剪（`TreeCuller`）+ LOD 三级细节
- 导出 = 矢量文本 PDF（`PdfExportService`）+ TaskPool 并发分块栅格（`PdfRasterJob`/`PdfTileTask`）
- 导入 = 业务指纹匹配（`IdentityMatcher`）+ 全局 uid 重映射（`UidRemap`）+ 关系图修复（`RelationGraph`）

## 三、核心服务（service/）——类名与方法名

### 3.1 树构建与布局

- **`TreeBuilder`**：`static build(people, filterFn?)` 扁平人物列表 → 森林（返回 `PersonNode[]` 根数组）；`static index(root)` 按 uid 建整树索引；`static depthOf(nodes)` 最大世代深度；内部 `linkSpouse()`（配偶双向补全）、`computeMetrics()`（分支高度/后代数），常量 `MAX_METRICS_DEPTH = 256` 防脏数据爆栈。
- **`TreeLayout`**：数据类 `EuBox`/`LineSeg`/`SpousePos`/`LayoutMetrics`/`EuCanvas`/`SuBox`/`SuCanvas`。
  - 欧式 `class EuLayout`：`static compute(roots, cardWidth, rowHeight, colGap, showSpouse, startY, allowed?, metrics?)`——自底向上「叶子计数 + 纵向堆叠」，按世次分列，配偶按生母分组引出子女。
  - 苏式 `class SuLayout`：`static compute(roots, cardWidth, dense, showSpouse, allowed?, metrics?)`——竖式吊线图，自底向上横向游标占位 + 位置回补；常量 `SuLayout.CARD_GAP = 34`、`SuLayout.START_X = 8`。
  - 辅助：`pushDoubleLine()`（朱砂红婚约双线）、`spouseOrder()`（正庶先后）、`suRootCenterX()`；含环检测（visiting 集合）。
- **`TreeCuller`**：`static euBoxes()/suBoxes()/lines()` 视口裁剪；预热 `warmupEu()/warmupSu()`；索引 `euIndexOf()/suIndexOf()/lineIndexOf()` 返回 `EuBoxIndex/SuBoxIndex/LineIndex`（按 y 排序数组 + 二分定位，O(N)→O(log N + K)）。
- **`TreeLayoutCache`**：单例 LRU，`MAX_ENTRIES = 8`，内部 `euMap/suMap/revision`；key = 宗支+revision+显示参数，布局时同步预热裁剪索引。
- **`TreeViewport`**：`class ViewRect`、`class ViewportMath.contentRect(offsetX, offsetY, viewW, viewH, zoom, margin)`——`屏幕 = 内容×zoom + offset` 反算 + 平移边界 clamp。

### 3.2 分页与 PDF 导出

- **`PaginationService`**：类型 `PageRootRef`（页根承接）、`PageCut`（切支：parentUid + childUids）、`PagePlan`、`PrintBook`（pages + indexByUid + pageCount）、`PageContent`（eu/su 二选一画布）；入口 `static async book(rootUid, style, version, profileName, onProgress?)`；防护常量 `MAX_PAGE_DEPTH = 256`、`MAX_PAGES = 20000`、`MAX_ITER = 400000`；用 **TaskPool @Concurrent 空任务作 yield** 防主线程 THREAD_BLOCK_6S；页脚接续 `pageGenText(page)`（「承第 N 页」）。
- **`PrintLayout`**：`class PageSpec`（`trimW = 320` / `trimH = 220` mm，`static landscape()`）；`class LayoutProfile`（印刷参数档位 standard/compact/large，毫米口径：装订口/翻口/天头/地脚/出血/安全内缩，奇偶页镜像版心）；屏幕分页与 PDF 共用。
- **`PdfExportService`**（整谱矢量 PDF，`@kit.PDFKit` 的 `pdfService` + `hidebug` 内存查询）：接口 `PdfExportOptions`（includeCover/volumeTitle）、`PdfVolume`、`PdfExportProgress`；OffscreenCanvas 仅作 `measureText` 度量 → 逐页 `insertBlankPage` + `addTextObject`（文字可选中/搜索）；两遍排版回填页码互引；按世代聚合分卷（单卷人数上限 `maxPerVolume`）；PSS 内存看门狗超限抛错分卷。
- **`PdfRasterJob`**（栅格几何常量）：`PAGE_W_MM = 320`、`PAGE_H_MM = 220`、`RENDER_DPI = 300`、`TILE_COLS = 2`、`TILE_ROWS = 2`（单块约 1890×1299px，避开 4096px 纹理上限）、`GUTTER_MM = 20`；实现函数 `renderTileImpl(pageNo, r, c, lineWidthMm, lineData, boxData, cacheDir)`。
- **`PdfTileTask`**：`@Concurrent async function renderTileJob(...)`——TaskPool 入口，仅转发到 `renderTileImpl`，避免 worker 重复解析大模块。
- **`PagedPdfExportService`**：`static async exportPdf(...)` 主入口；`addTile(page, tile)`（300dpi 栅格按 pt 落位）、`renderTiles()`（TaskPool 并行）/`renderTilesSerial()`（主线程兜底）、`addTextObjects(...)`（矢量文本层叠加）、`cleanupTiles()`；常量 `PAGED_MAX_PAGES_PER_VOLUME = 8`。

### 3.3 同步与数据

- **`CloudSyncService`**：常量 `ZONE_NAME = 'miyuanzupu'`、`MAX_VIDEO_BYTES = 500MB`；`backupAll(progress)` / `restoreAll(progress, force)` / `getUsage()` / `countBookMembers()`；内部 `MediaJob` 分桶上传、`compressImage`（长边 1920、JPEG 80）；图片落本地缓存、视频保留 cloud:// 惰性下载。云端对象类型 `CloudFamilyMember`/`CloudFamilyMedia`/`CloudGraveLocation`。
- **`FamilySyncService`**：`syncCurrent(reason, onProgress?)` / `fullResync(onProgress?)` / `isRunning()` / `personFromRow(raw)`；同步链路 = outbox 推送（→`member-direct-write`/`change-submit`）→ `sync-pull` 按 rev 增量拉取（PAGE_SIZE 分页 while 循环，guard 上限 20）→ 回放 RDB → 更新 sync_state；事件常量 `BOOK_CHANGED = 'SYNC_BOOK_CHANGED'`。
- **`OutboxService`**：`class OutboxItem`（op/scope/target/targetName/payload/baseRev/state/retryCount）、`OutboxState`（`PENDING/DONE/FAILED` 状态机）；RDB 表 `outbox`（字段 `id, family_id, op, scope, target, target_name, payload, base_rev, state, retry_count`）；`enqueue(store, item)` + 重试。
- **`GenealogyService`**：RDB（`@kit.ArkData` relationalStore）单例数据层；DB `genealogy.db`；表 `person`、`genealogy`（谱册）、`person_spouse_v2`（book_id/uid/spouse_uid…）、`app_meta`（键 `initialized`）。
- **`FamilyService`**：云函数唯一封装层 + 写路径编排（在线直写 / 离线入 Outbox）；方法 `bindLocalBook()`、`createFamily()`、`joinFamily()`、`directWrite()`、`submitChange()`、`reviewChange()`、`requestAccess()`、`reviewAccess()`、`deleteCloudFamily()` 等（映射见 §6.3）；AppStorage 键 `gpSyncMode/gpFamilyRole/gpSyncStatus/gpPendingCount/gpFamilyTitle/gpOffline`。

### 3.4 导入与体检

- **`ImportPlanner`**：`static async plan(incoming, local, retired, opt, onProgress?)` 三段式合并——① `class IdentityMatcher`（`static normalizeName()` 归一化 + 业务指纹打分：姓名/性别/生日/父母/世代/配偶，`ImportOptions.autoMergeScore = 85`）② `UidRemap` 全局重映射（`UidAllocator` 一次性建索引 + 只前进游标摊销 O(1)）③ `RelationGraph` 就地修复；结果类型 `IdentityMatch`（merge/new/skip）、`ImportPlan`、`ImportResult`；纯内存可预览可回滚。
- **`RelationGraph`**：悬空引用清理、配偶双向补齐、按树深度回填世代。
- **`IntegrityService`**：`check()`（单列表体检）、`compare()`（同编号跨版本比对）、`checkIdentity()`、`reused()`（已删编号复用）、`reusedReferences()`、`incoming()`（导入前综合体检）、私有 `checkReferences()/checkCycles()/checkSuspectDuplicate()/tooYoungParent()`。
- **`IdGenerator` / `UidAllocator`**：男 F/女 M 前缀，复用最小空号。

### 3.5 其他服务

- **`AccountService`**：`@kit.AccountKit authentication` + `@hw-agconnect/auth`；`callFunction(name, payload)`（见 §6.3）、`LoginOutcome`。
- **`ShareService`**：`buildInviteCode()` / `parseInviteCode`（三段式 `familyId.ownerUserId.bookKey`）+ `@kit.ShareKit systemShare` 系统分享面板；类型 `InviteInfo`。
- **`ExportService`**：JSON/CSV/Markdown 导出（类 `JsonBundle`）。
- **`PrivacyService`**：`PrivateContact`、`loadAll/get/clear/erasureHint`（谱主隐私字段缓存）。
- **`DirectoryService`**：黄页（`MEMBER_COUNT_BANDS` 规模分档）。
- **`DisplayService`**：`OrientationMode` 枚举、键 `KEY_ORIENTATION = 'gpOrientation'`。
- **`ConsentService`**：协议同意状态键 `gpPrivacyAgreed`。
- **`InsightService`**：`birthdaysOfMonth()` 等统计洞察。

## 六、云侧（CloudProgram）

### 6.1 公共层 `_shared/`（部署时复制为各函数 `node_modules/_zupu_shared`，零第三方依赖）

- **index.js**：`createHandler(name, body)` 统一入口（返回 `(event, context, callback, logger)`）；`extractParams(event)` 多落点兜底解析（value/params/data/body/queryStringParameters）；`getFamily(familyId)`；`reply()` 同时兼容返回值与 callback 两种约定；BizError 业务码出口，内部异常只进日志（防 CWE-209）。
- **identity.js**：`resolveUid(event, params)` / `requireUserId()`（无 uid 抛 401）/ `verifyTokenRemote(candidate)` 远端令牌校验；`fromGateway` 网关注入身份，绝不信任端侧自报 uid。
- **authz.js**：`ROLE_RANK = { OWNER: 3, EDITOR: 2, VIEWER: 1 }`；`requireMember(familyId, userId, minRole)`；`effectiveMembership()` 惰性失效（到期置 EXPIRED）+ 谱主自愈；`inBranchSubtree(uid, branchRootUid)` 沿父链上溯 ≤64 层判子树越权。
- **db.js**（SDK `@hw-agconnect/cloud-server`）：`query/queryOne/getById/upsertMany/upsertOne/deleteByType/count/writeBatch`；凭据链 `ensureCloud()`：环境变量 `AGC_CONFIG` → 包内 `agconnect-credential.json`（`findBundledCredential`）→ `PROJECT_CREDENTIAL`；`Region.REGION_CN`，默认 zone `miyuanfamily`。
- **rev.js**：`allocate(family, retries)` Family.rev 读-改-写 + 回读 CAS（环境变量 **`REV_CAS_ENABLED=1`** 开启，冲突重试默认 2 次）；`changeLogRow(p)`、`changeLogId(familyId, rev)`（格式 `{familyId}#{rev}#{seq}` 防撞键）。
- **patch.js**：`parsePatch(patchJson)` / `applyPatch(target, patch)`（`{字段:{b,a}}` 结构）；白名单 `PATCHABLE_FIELDS`（uid/generation/name/gender/birthDate/fatherId/spouseId/biography/graveLng… 等 28 字段）；传记走分段模型只允许 `APPEND_TEXT`。
- **validate.js**：`assertUniqueUid`、`assertNoCycle`（父子链成环检测）、`generationWarning`、`assertPayloadSize`（`MAX_PAYLOAD_BYTES = 900KB`）、`assertDirectoryPayload`（黄页字段白名单）。
- **privacy.js**：`splitPerson`（phone/wechat/residence 拆到 FamilyPrivate，主行留 `privateRef`）、`buildGraveRow`、`toPublicPayload`、`round4`。
- **core.js**：`BizError`（code/message/reason）；`CODE = { OK:200, BAD_REQUEST:400, UNAUTHENTICATED:401, FORBIDDEN:403, NOT_FOUND:404, CONFLICT:409, TOO_MANY:429, INTERNAL:500 }`；`newInviteCode`、`distanceMeters`、`str/num/bool/uuid`。
- **constants.js**：对象类型表 `T = { FAMILY, MEMBERSHIP, MEMBER, BOOK, CHANGE_REQUEST, CHANGE_LOG, MEDIA, GRAVE, ACCESS_REQUEST, DIRECTORY, TEXT_SEGMENT, USER_DEVICE, PRIVATE }`；枚举 `ROLE`、`MEMBERSHIP_STATUS`（INVITED/ACTIVE/REVOKED/EXPIRED）、`CHANGE_STATUS`（PENDING/APPROVED/REJECTED/SUPERSEDED）、`ACCESS_KIND`（VIEW_APPLY/JOIN_CLAIM）、`OP`（ADD/UPDATE/DELETE_REQ/APPEND_TEXT）；`PRIVATE_FIELDS=['phone','wechat','residence']`；`MAX_BATCH=100`；`VIEW_APPLY_DEFAULT_DAYS=180`。
- **members.js**：`memberIdOf`（familyId#uid）、`buildMemberRow/buildPrivateRow/buildBookRow`、`parentMapOf/personMapOf`。**human.js**：`diffText`（「字段：旧值→新值」摘要）。

### 6.2 业务云函数（均 `module.exports.handler = S.createHandler('<名>', ...)`）

| 函数 | 职责 → 实现要点 |
|---|---|
| `family-create` | 建族 + familyId/inviteCode + OWNER Membership（`core.newInviteCode`） |
| `family-join` | 凭 inviteCode 入族（索引查询 + 有效期/角色校验） |
| `family-list-mine` | `listMemberships` + 惰性失效刷新 |
| `family-bootstrap` | 首次接入批量导入（`members.buildMemberRow` + `db.writeBatch`，`MAX_BATCH=100`） |
| `family-delete` | 谱主删族（confirmTitle 防误触；无跨表事务，先子表后主表逐表清空） |
| `family-acl-list` / `family-acl-set` | 成员管理：角色/分支/期限/状态 + `ROTATE_INVITE` 轮换邀请码；`Family.aclVersion+1` |
| `member-direct-write` | OWNER 直写（LWW）：`rev.allocate` + ChangeLog + `writeBatch` 原子批写 |
| `change-submit` | 编辑者提交变更单：只写 `ChangeRequest(PENDING)`；频控（同提交者 1 分钟≤10 条）；`inBranchSubtree` 越权校验；`assertNoCycle` + `generationWarning`；`baseRev` 乐观并发 |
| `change-list-pending` | 待审列表（OWNER 看全部，EDITOR 仅认领分支内） |
| `change-review` | 审批：baseRev 过期→`SUPERSEDED` 退回；APPROVED→`applyPatch` + `rev.allocate` + ChangeLog 一批原子写；`DELETE_REQ` 写软删墓碑（deleted=true） |
| `access-request` / `access-list` / `access-review` | 访问申请：applicantId 由云函数按可信身份写入；PENDING 幂等；防刷限频（10 分钟≤3 次）；通过唯一动作=写 `Membership` |
| `sync-pull` | 家族数据唯一读取通道（见 §6.5） |
| `family-private-get` | 隐私字段读取（仅 OWNER，按 `privateRef` 回查 FamilyPrivate） |
| `grave-update` / `grave-list-public` | 墓位更新（`buildGraveRow`，round4）/ 公开聚合查询 |
| `media-record` / `media-list` | 媒体登记：`safeCloudPath` 防路径穿越（拒 `..`/绝对路径/反斜杠，CWE-22） |

### 6.3 端侧调用方式与映射

- **云函数调用**（`AccountService.callFunction(name, payload)`）：`@kit.CloudFoundationKit` 的 `cloudFunction`——构造 `cloudFunction.FunctionParams = { name, version: '$latest', timeout, data: payload }` → `await cloudFunction.call(request)` → 从 `FunctionResult.result` 归一化取结果。
- **云数据库**：端侧不直接使用 CloudDB API（协作 Zone 端侧 `[]` 权限），读写全部经云函数；个人备份走 `cloudDatabase`/`cloudStorage`（Zone `miyuanzupu`）。
- **FamilyService → 云函数映射**：`listMine()`→`family-list-mine`；`createFamily()`→`family-create`；`joinFamily()`→`family-join`；`listMembers()`→`family-acl-list`；`updateMember()/rotateInvite()`→`family-acl-set`；`directWrite()`→`member-direct-write`；`submitChange()`→`change-submit`；`listPendingChanges()`→`change-list-pending`；`reviewChange()`→`change-review`；`requestAccess()`→`access-request`；`reviewAccess()`→`access-review`；`listPendingAccess()/listMyAccess()`→`access-list`；`deleteCloudFamily()`→`family-delete`。

### 6.5 sync-pull 接口契约

- **入参**：`familyId`、`sinceRev`（默认 0，=0 走全量基线）、`limit`（默认 200，上限 1000）、`offset`；鉴权 `requireMember(familyId, userId, ROLE.VIEWER)`。
- **出参**：`headRev`（家族当前 rev，作下一轮 sinceRev）、`fullSnapshot`、`hasMore`/`nextOffset`（全量分页续传）、`changes`（增量：`logId/rev/action/targetMemberId/summary/actor`，latestByTarget 去重）、`members`、`graves`、`book`、`role/branchRootUid/expireAt`（端侧按角色渲染）、`privates`（**仅 OWNER 回流**）。

### 6.6 同步闭环

- 写入：所有写路径收敛到 `rev.js`（`rev.allocate` + 同批 `writeBatch` 原子写 ChangeLog）。
- 审核：`change-submit`（PENDING）→ `change-list-pending`（按角色可见）→ `change-review`（baseRev 乐观并发 + 合入新 rev）。
- 读取：端侧推 Outbox → `sync-pull` 增量拉取 → 回放 RDB，双向收敛于 `Family.rev` 游标。
