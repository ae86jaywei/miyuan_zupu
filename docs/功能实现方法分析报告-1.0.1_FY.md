# 觅源族谱 功能实现方法分析报告

- 仓库：https://atomgit.com/ae86jay/miyuan_zupu
- 分支：`1.0.1_FY`（HEAD：c1aa131）
- 范围：端侧 `Application/entry/src/main/ets`（ArkTS/鸿蒙）+ 云侧 `CloudProgram`（AGC 云函数/云数据库）
- 说明：只列关键方法/技术名称，不含详细代码。

## 一、总体架构

- **端侧 RDB 为唯一真相源** + **Outbox 离线队列** + **基于 revision 的增量同步**
- 大树渲染 = 布局 LRU 缓存 + 二分索引视口裁剪 + LOD 分级细节
- 导出 = 矢量文本 PDF（长任务 TaskPool 化 + 分块栅格）
- 导入 = 业务指纹匹配 + 全局 uid 重映射 + 关系图修复

## 三、核心服务（service/）

| 服务 | 实现方法（关键名称） |
|---|---|
| TreeBuilder | 扁平列表 → 森林（Map 索引 + 父/母/配偶三向关联、双向补全），递归深度上限 256 防爆栈 |
| TreeLayout | 欧式：自底向上「叶子计数 + 纵向堆叠」按世次分列；苏式：竖式吊线图，横向游标占位 + 位置回补；含 visiting 集合环检测 |
| TreeCuller | 视口裁剪：WeakMap 缓存按 y 排序索引 + 二分定位 + 区间扫描，O(N)→O(log N + K) |
| TreeLayoutCache | 单例布局缓存，key=宗支+revision+显示参数，容量 8 条 LRU（Map 插入序），布局时预热裁剪索引 |
| TreeViewport | 视口数学：`屏幕 = 内容×zoom + offset` 反算 + 平移边界 clamp |
| PaginationService | 印刷分页规划（PageBook/PagePlan：页根、切支、页脚接续「承第 N 页」、奇偶镜像）；TaskPool @Concurrent 空任务作 yield 防主线程 THREAD_BLOCK_6S |
| PdfExportService | 矢量 PDF：OffscreenCanvas 仅作 measureText 度量 → pdfService 逐页 insertBlankPage + addTextObject（文字可选中）；两遍排版回填页码互引；PSS 内存看门狗分卷 |
| PdfTileTask / PdfRasterJob | TaskPool 并发栅格：300dpi 位图按 2×2 分块渲染避开 4096px 纹理上限，矢量文字层叠加 |
| PrintLayout | 印刷页规格（320×220mm 横版：装订口/出血/安全内缩，奇偶页镜像版心），屏幕分页与 PDF 共用 |
| CloudSyncService | AGC 云数据库/云函数 + 媒体对象存储；图片落本地缓存、视频保留 cloud:// 惰性下载；媒体任务分桶上传 |
| FamilySyncService | 同步编排：推本地 Outbox → 按 rev 增量拉取（sync-pull）→ 回放进 RDB → 更新 sync_state |
| OutboxService | 离线 Outbox 队列（RDB 表，字段级 diff/baseRev/PENDING-DONE-FAILED 状态机 + 重试） |
| RelationGraph | 关系图就地修复：悬空引用清理、配偶双向补齐、按树深度回填世代 |
| IntegrityService | 一致性体检（只判不改）：重复/非法 UID、悬空关系、成环、双版本同 ID 比对 |
| ImportPlanner | 三段式导入合并：①业务指纹（姓名/性别/生日/父母/世代/配偶）打分匹配 ②全局 uid 重映射 ③RelationGraph 修复；纯内存可预览可回滚 |
| ShareService | 三段式文本邀请码（familyId.ownerUserId.bookKey）+ systemShare 系统分享面板 |
| GenealogyService | RDB relationalStore 单例数据层 |
| FamilyService | 云函数唯一封装 + 写路径编排（在线直写 / 离线入 Outbox） |
| IdGenerator/UidAllocator | 男 F/女 M 前缀、复用最小空号；一次性建索引 + 只前进游标摊销 O(1) |

## 四、五种谱式渲染（components/tree/）

| 谱式 | 渲染方法 |
|---|---|
| EuTree 欧式 | Canvas 绘制，外层 translate + 内层 scale；布局缓存 + 视口裁剪（1 屏缓冲）；LOD 三级（完整卡片→姓名骨架→聚合气泡） |
| SuTree 苏式 | 同 EuTree 管线，竖式吊线布局 |
| PagodaTree 宝塔式 | 上窄下宽按世代分行，FlatListSource + List/LazyEach 窗口化渲染 |
| ModernTree 现代式 | 按世代分组卡片列表，同样窗口化 |
| DieRecord 牒记式 | 逐世文字编记列表（一人一条），传引用避免深拷贝 |
| PagedTree 印刷分页 | PrintCard（22mm 白底卡）按 PagePlan 渲染，切线/页脚接续 |

## 五、画布交互与工具（view/、util/）

- **TreeCanvas**：双指捏合缩放（0.05~1.5）+ 单指拖拽平移；多宗支堆叠画布；手势进行中子画布 LOD 降级、抬手恢复；聚合气泡点击放大到固定 zoom
- **GenealogyStore**：AppStorage 驱动的全局状态（gpVersion 版本号 + @StorageProp/@Watch 订阅；统一 createIfAbsent+set 防丢刷新）
- **LunarUtil**：纯历法公式（1800~2100 干支/生肖/四柱）+ 内置节气分钟表定月建，超范围降级
- **TreePerf**：性能打点（calls/totals/max，>1s 主线程长任务 hilog 告警）
- **TreeScrollMemory**：谱式切换作废 AppStorage 滚动位置键，防定位到空白
- **FlatListSource**：实现 IDataSource + DataChangeListener 的列表数据源

## 六、云侧（CloudProgram）

### 6.1 云函数公共层（_shared/）

- **统一入口**：`createHandler` 包装，extractParams 多落点兜底解析，统一 ok/fail 出口；BizError 业务码与内部异常隔离（防 CWE-209）；共享库零第三方依赖，部署时复制注入
- **identity**：网关注入身份 → 令牌远端校验（verifyTokenRemote），不信任端侧自报 uid
- **authz**：基于 Membership 的角色门禁（ROLE_RANK：OWNER>EDITOR>VIEWER）；过期惰性失效 + 谱主自愈；`inBranchSubtree` 沿父链上溯 ≤64 层做分支越权校验
- **rev**：家族级 revision 分配（读改写 + 尽力 CAS + 宽松单调兜底）；ChangeLog.logId=`familyId#rev#seq` 防撞键
- **patch**：字段级 diff patch（`{字段:{b,a}}`）+ 白名单校验；传记走分段模型只允许 APPEND_TEXT
- **validate**：云侧结构护栏——UID 唯一、父子链成环检测、世代异常告警、payload 大小限制
- **privacy**：活人隐私隔离——phone/wechat/residence 拆到 FamilyPrivate，主行只留 privateRef
- **human**：diffText 生成「字段：旧值→新值」可读摘要（审批流水）

### 6.2 业务云函数

| 函数 | 职责 → 实现方法 |
|---|---|
| family-create / family-join | 建谱/邀请码加入（inviteCode 索引查询 + 有效期校验） |
| family-bootstrap | 谱初始化批量导入（writeBatch 批量 upsert） |
| family-delete | 解散：无跨表事务，先子表后主表逐表清空 |
| family-acl-set/list | 谱主改角色/期限/轮换邀请码，Family.aclVersion+1 |
| member-direct-write | OWNER 直写：rev.allocate + ChangeLog + writeBatch 原子批写 |
| change-submit | 编辑提交待审：只写 ChangeRequest(PENDING)；频控（1 分钟≤10 条）、分支越权、成环检测、baseRev 乐观并发 |
| change-review | 谱主审核：baseRev 过期→SUPERSEDED；合入=applyPatch+新 rev+ChangeLog 一批原子写；删除=软删墓碑 |
| access-request/review/list | 访问申请审批：PENDING 幂等、防刷限频，通过唯一动作=写 Membership |
| directory-upsert/search | 黄页上架/搜索：下架物理删除；服务端字段白名单拒绝人物数据 |
| grave-update / grave-list-public | 祖墓维护/公开查询（公开表端侧可直读） |
| media-record / media-list | 媒体登记：safeCloudPath 防路径穿越（拒 `..`/绝对路径） |
| **sync-pull** | 唯一读取通道：sinceRev=0 全量分页快照；sinceRev>0 按 ChangeLog rev 增量拉取（latestByTarget 去重）；隐私字段仅回流 OWNER |

### 6.3 数据模型（CloudDB objecttype）

- **Family**：ownerUserId、rev（版本游标）、aclVersion、inviteCode（索引）
- **FamilyMember**：memberId=familyId#uid、parentId 父亲链、payload JSON 大包、软删墓碑（deleted）；索引 `index_familyId_rev` 支撑增量拉取
- **FamilyPrivate**：活人隐私独立表，仅 OWNER 经云函数读
- **Membership**：familyId#userId，role/status/expireAt/branchRootUid——全系统唯一授权表
- **ChangeRequest / ChangeLog**：待审变更 / rev 变更流水
- **FamilyTextSegment / FamilyMedia / FamilyDirectory / FamilyGraveLocation / UserDevice**：分段长文、媒体、黄页、墓位、推送设备
- 权限模式统一：World `[]`、Authenticated/Creator 仅 Read、Administrator 读写删

### 6.4 同步闭环

写入：所有写路径收敛到 rev.js（rev 分配 + 同批原子写 ChangeLog）
审核：change-submit（PENDING）→ change-list-pending（按角色可见）→ change-review（乐观并发 + 合入新 rev）
读取：端侧推 Outbox → sync-pull 增量拉取 → 回放 RDB，双向收敛于 Family.rev 游标
